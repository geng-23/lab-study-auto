# 实验室安全教育平台自动切换脚本

## 用途

本项目只适用于中国科学技术大学化学与材料科学学院2026级新生实验室安全准入考试，目前仅在该页面验证。原准入考试需要学生完成8小时8分钟的必选学习内容之后，才能参与正式考试；本项目采取无人值守、自动学习的方式，帮助学生顺利通过学习，并不修改系统本身计时或学习记录。最佳使用方式为执行过夜
在“学习详情”页，等待当前章节的页面计时达到“要求学习”并多留 3 秒后，按顺序处理其余必学章节，再处理选学章节。脚本不改动平台计时、请求或学习记录，也不会自动开始考试。

## 使用

1. 在 Edge 中登录[实验室安全教育平台](https://sysaq.ustc.edu.cn/lab-study-front/home)，点击个人中心-我的考试-去学习，点击准备开始的章节旁边的“去学习”，进入学习详情页，并保持该标签页打开。
2. **在左侧的章节列表处向上滑动，直到所有章节都加载完毕（很重要）**
3. 按 F12，选择“控制台”（Console）。
4. 打开 lab-study-auto.js，复制全部内容，粘贴到控制台后按 Enter。若 Edge 阻止粘贴，请先核对脚本内容，再决定是否按浏览器提示操作（一般是输入“允许粘贴”四个汉字，根据实际情况来）
5. 脚本会弹出输入框。填写起始章节的完整名称或当前列表序号；从第一章开始可填写 1。同名章节请用序号。
   输入框会显示当前找到的项目数。**若列表尚未加载完整，请先把其余项目加载出来**，再运行脚本。
6. 页面右下角会出现状态框，绿色表示运行中、橙色表示需要处理、红色表示异常停止、蓝色表示已完成。状态框显示当前章节、页面计时、本次处理数量和最近事件，可暂停或停止。
7. 刷新页面会停止脚本；需要继续时重新执行。脚本会跳过页面标记已完成的项目，不会固定跳过任何人的章节。

## 注意

- 脚本只根据页面显示的实际计时切换；具体学习时长以各自的任务页面为准。
- 标签页进入后台时，浏览器可能放慢页面计时。脚本若发现计时停滞，会暂停。
- 页面有约 5 分钟无操作提醒，随后约 15 秒自动退出。脚本会处理这个已识别的“是否继续”提示；遇到其他确认框会暂停。
- 运行前请先把左侧章节列表全部加载出来。脚本只使用当前列表，不会滚动页面请求后续章节。若页面布局更新，选择器可能失效，脚本会停下并提示。
- 夜间运行时，**电脑必须保持开机和联网，Edge 页面不能关闭或刷新**。Windows 睡眠、登录失效、断网、浏览器后台限速、平台报错、视频或微课堂跳转、页面结构变化，都可能使脚本暂停或停止。**无法保证完全无人值守成功；早上请检查状态框与平台累计时长**。
- 对脚本执行失败、系统异常、学习判定无效等异常情况概不负责，请自行斟酌是否使用。
- 平台可能延迟更新总时长；列表处理完后，请等待并核对顶部的“必学时长”和“选学时长”。

停止命令（控制台）：`window.labStudyAutoNext.stop()`
